# rishabsjain.github.io

Personal site built with React and [Vite](https://vite.dev/). Requires Node `^20.19.0` or `>=22.12.0`.

## Available Scripts

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally.

### `npm run deploy`

Builds the app and publishes the `build` folder to GitHub Pages.
